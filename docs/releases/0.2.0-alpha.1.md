**Peer is an AI coding workspace that keeps you in the decisions.** It runs a real coding agent (bundled OpenCode, or your own Claude Code or Codex) and adds a collaboration engine that decides when to just do the work, when to discuss a trade-off with you, and when to ask for your reasoning first.

This is the first public **alpha**. Expect rough edges, and please [report what breaks](https://github.com/OmarAshour02/peer/issues/new/choose).

## Install

**macOS and Linux, one line:**

```bash
curl -fsSL https://raw.githubusercontent.com/OmarAshour02/peer/main/scripts/install.sh | sh
```

The script downloads the build for your machine from this release, checks it against `SHA256SUMS.txt`, and installs it. On macOS that means `Peer.app` in `/Applications`; on Linux, an AppImage with a `peer` command in `~/.local/bin`.

**Or download an installer below:**

| Platform | File |
|---|---|
| macOS, Apple Silicon | `Peer-0.2.0-alpha.1-mac-arm64.dmg` |
| macOS, Intel | `Peer-0.2.0-alpha.1-mac-x64.dmg` |
| Linux x64 | `.AppImage` or `.deb` (`amd64`) |
| Linux arm64 | `.AppImage` or `.deb` (`arm64`) |

> **macOS: the alpha is not notarized by Apple.** Installing with the script above avoids any warning. If you use the DMG, macOS will say it can't verify the developer the first time you open Peer. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**. You only need to do this once.

Windows is not supported yet.

## What's in it

- **Two ways to work.** *Collaborate* (default): the agent handles routine work and brings you in on decisions that shape the result. *Learn*: the agent asks for your hypothesis or reasoning before meaningful changes, with progressive hints.
- **Temporary controls.** Just do it, Discuss first, Give me a hint, Direct answer, and You decide on a single question. They don't change the session's mode.
- **Pauses that are enforced.** On supported runtimes, Peer holds tool calls and locks code changes while a checkpoint is open. It doesn't rely on the model choosing to stop.
- **Decisions the agent might skip.** Peer catches new dependencies and edits to public API contracts before they run. An optional approach gate pauses a task before its edits pass five files.
- **Adapts to you.** Peer asks less when you keep delegating, within a session and across sessions. This uses only local history, and you can reset it.
- **Your runtimes.** Bundled OpenCode (connect any provider or a local model: Ollama, LM Studio, any OpenAI-compatible server), plus your own Claude Code and Codex CLIs.
- **A redesigned workspace.** Light and dark themes; streaming markdown with math and Mermaid diagrams; session search; a changes panel; undo the last turn; general chats that aren't tied to a project; and an opt-in per-session YOLO mode that approves permission prompts.

Everything stays on your machine: projects, sessions, and history are stored in a local SQLite database. Model requests go through the runtime and provider you choose.

## Known limits

- **Gemini CLI is experimental and read-only.** It can explore and propose changes but not apply them. A live Gemini turn has not been tested yet.
- **Codex can't be stopped before an MCP tool runs.** Peer detects a non-read-only MCP call after it starts and aborts a locked turn.
- **Detection is scoped.** Peer inspects recognized tool calls and manifests. Changes made through shell commands, scripts or generators (for example, a rename with `mv`) can skip a detected-decision pause, and the approach gate doesn't count shell-driven edits.
- **Runtime settings** (CLI paths, Claude permission mode, Codex reasoning effort) are covered by unit tests but haven't been verified end to end against each CLI.
- **No auto-update.** Run the install command again, or download the new installer, to update.
- **macOS builds are ad-hoc signed.** macOS may ask again for permissions you granted Peer (such as folder access) after you update to a new build.
- **No custom app icon yet.**

The full behavior contract, including exactly what each runtime enforces, is in [PEER.md](https://github.com/OmarAshour02/peer/blob/main/PEER.md).

## Requirements

- macOS 13 Ventura or later (Apple Silicon or Intel), or Linux x64/arm64 with glibc. AppImages need FUSE 2 (`libfuse2`).
- For Claude Code or Codex sessions: the CLI installed and logged in (`claude auth login`, `codex login`). OpenCode is bundled.
